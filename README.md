# Personal Portfolio

This is my personal portfolio showcasing my skills, projects, and experiences. 

## Features
- Responsive design
- Interactive UI
- Multiple sections including About, Projects, Skills, and Contact
- Easy navigation

## Tech Stack
- HTML
- CSS
- JavaScript
- React.js
- Node.js

## Quick Start
To get started with the project, clone the repository and install the necessary dependencies:

```bash
git clone https://github.com/pranav3142/PersonalPortfolio.git
cd PersonalPortfolio
npm install
npm start
```
